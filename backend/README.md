# Gestion Hub Evenementiel — Monorepo (Angular + Spring Boot)

Application web de gestion de hub évènementiel — **frontend Angular** + **backend Spring Boot**.

## Sommaire
- [Prérequis](#prérequis)
- [Démarrage rapide (dev)](#démarrage-rapide-dev)

---

## Prérequis

- **Java 25** (OpenJDK)  
- **Maven 4.0**

## Démarrage rapide (dev)
Backend
cd backend
mvn -q -DskipTests clean package
mvn spring-boot:run
écoute sur http://localhost:8080
